01 / REPÉRER

Les informations sont dans les réglages.

À l’arrêt, sans clé de mise à jour branchée : Menu → Configuration → Général → Mise à jour du logiciel. Relevez les valeurs affichées. Si une information n’est pas accessible, laissez « Je ne sais pas ».
